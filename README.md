# Syed Ali Hamad Gilani — portfolio

The source of **https://syedalihamadgilani.site** — AI automation engineer and
web developer.

Astro 5, static: four pages, **zero JavaScript shipped**. Every effect is CSS —
scroll-driven animation timelines, `:has()` filters, a CSS typewriter — and the
phone layout is its own design, not a shrunk desktop. The expertise pictures
and the phone diagrams are built at build time from real workflow data, and
the headings are split into words at build time so they can rise word by word.

    npm install
    npm run build      # output in dist/

Deployed on Vercel from this repository: every push to `main` goes live.
